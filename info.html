SETUP GUIDE

From download to
your first warning.

Lock uses the League Client’s local lockfile to understand when champ select begins and which champion you are hovering.

!
IMPORTANT FOR POPUP DETECTION

Keep Lock on Home or Profile while you queue.

These are the two recommended app pages for the complete live workflow. Leave either page open before champ select so the status and off-pick popup work exactly as intended.

⌂ HOME♙ PROFILE
01

Open League Client

Launch League of Legends and leave the Riot/League Client running. Lock connects only to the client on your own PC.

02

Let Lock find the lockfile

Lock normally detects the League lockfile automatically. It contains the temporary local port and authorization details required to read champ select.

03

Set it manually if needed

If auto-detection fails, open Lock Settings and select your League lockfile. The common location is C:\Riot Games\League of Legends\lockfile.

C:\Riot Games\League of Legends\lockfile
04

Choose your pool

Select 2–5 champions in Champion pool. These become the only picks treated as your ranked comfort pool.

05

Return to Home or Profile

Before entering champ select, keep Lock open on Home or Profile. These two pages keep the complete live status flow visible and allow the popup warning to work as intended.

06

Queue and stay locked

When you hover a champion, Lock checks it instantly. In-pool picks stay clean; an off-pool hover triggers the warning popup.

WHAT IS A LOCKFILE?

A temporary local key created by League Client.

It tells Lock which local port the League Client is using and provides temporary authorization for that running session. Lock reads it only on your computer to detect client state and champ select. Restarting League creates a new session, and Lock reconnects automatically.
